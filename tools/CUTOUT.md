# 去背：用分割，不要用生成

`tools/cutout.py` — 用 U²-Net / IS-Net 預測人像遮罩來去背。

它放在 mdream 的 repo 裡，是因為它回答的是「什麼時候**不要**用 mdream 的 edit」。
兩者原理根本不同：

- **mdream edit**：照著參考圖**重畫**整張畫布。像素全部是新生成的。
- **cutout.py**：只預測一張 alpha 遮罩，**原始像素原封不動**。

實測同一張 1536×2048 的人像：

| | mdream edit | cutout.py |
|---|---|---|
| 時間 | 680–756 s | **1.9 s** |
| 主體保真 | 會漂移（構圖、顏色、細節） | **alpha=255 處逐位元相同** |
| 透明背景 | 做不到（模型只有 RGB） | **可以** |
| 硬體 | GPU、16 GB 權重 | CPU、176 MB |
| 能做的事 | 換衣服、變老、改光線 | 只有去背 |

**去背這件事不用考慮，就用 cutout.py。** mdream edit 的價值在需要理解語意的改動。

## 不用安裝任何東西

`onnxruntime` 已經在 `~/.venv`，權重也已經在 `~/.u2net/`（rembg 的快取目錄，之前某個工具下載的）。**不需要裝 rembg。**

```bash
~/.venv/bin/python ~/repos/mdream/tools/cutout.py in.png \
    -o out_rgba.png --white out_white.png
```

- `-o` 輸出 RGBA（透明背景）
- `--white` 另外輸出一張白底合成版
- `--model` 換模型，預設 `isnet-general-use`

## 模型檔

`~/.u2net/` 裡有四個，這支工具支援三個：

| 檔案 | 輸入尺寸 | 用途 |
|---|---|---|
| `isnet-general-use.onnx` | 1024×1024 | **預設**。邊緣最利，通用主體 |
| `u2net_human_seg.onnx` | 320×320 | 專門切人，快一點，邊緣較軟 |
| `u2net.onnx` | 320×320 | 通用顯著物體偵測 |
| `u2net_cloth_seg.onnx` | 768×768 | **不支援**——它輸出 4 個類別通道（上半身／下半身／全身），不是 alpha，要另一套後處理 |

實測（同一張圖，遮罩品質）：

```
                       主體佔比   完全不透明   半透明邊緣
u2net_human_seg         45.8%      16.5%      1.17%
isnet-general-use       45.7%      45.2%      0.47%   ← 邊緣最利
```

`isnet` 在 1024×1024 推論，`u2net` 只有 320×320 再放大，差別主要在這裡。實際看帽沿和耳朵：`u2net_human_seg` 有一圈藍色溢色（背後藍色船身的殘留），`isnet` 沒有。

## 兩個踩過的坑

**一、正規化是逐模型不同的，弄錯不會報錯，只會安靜地變差。**

```
u2net / u2net_human_seg   320×320    mean (0.485,0.456,0.406)  std (0.229,0.224,0.225)
isnet-general-use        1024×1024   mean (0.5,0.5,0.5)        std (1.0,1.0,1.0)
```

我第一版工具對所有模型都套 u2net 的 ImageNet 正規化，`isnet` 照樣跑得出遮罩、看起來也像那麼回事，但品質是打折的。這種錯誤沒有例外訊息，只能靠讀 rembg 的 session 類別去核對。

**二、IS-Net 的機率幾乎不會到 1.0。**

原始輸出只有 **0.1%** 的像素落在 alpha 255，等於整個主體都是半透明，合成到白底會被洗淡。所以預設加了一道 alpha 拉伸：

```
alpha' = clip((alpha - 0.05) / 0.90, 0, 1)
```

拉伸後完全不透明的比例從 0.1% → 45.2%，而且恢復了最重要的性質：**主體內部的輸出像素就是輸入像素**。要看原始機率用 `--raw-alpha`，門檻用 `--lo/--hi` 調。

## 已知限制

- 遮罩是低解析度推論再放大的，**髮絲級的細節切不乾淨**。要頭髮就得上 alpha matting（rembg 的 `alpha_matting=True`，或 `pymatting`），這支工具沒做。
- 背景顏色會沿邊緣溢色。`isnet` 好很多但沒有完全消除，真的要乾淨得做 despill。
- 只認「主體 vs 背景」。要切特定物件（只要帽子、只要衣服）得用別的模型。
- 跑在 CPU 上。1536×2048 約 1.9 秒，沒有優化的必要。

## 什麼時候用哪個

```
要保留原始像素、要透明背景、只是去背        → cutout.py
要換衣服、變年齡、改光線、改背景內容        → mdream edit
兩者都要（去背後再重繪背景）                → 先 cutout.py 拿遮罩，再合成
```
